---
name: Recipe provenance for MVP evaluation
description: Why MVP evaluation needs source-checked real recipes rather than plausible synthetic examples.
---

Use real recipes researched online, with proper data, for evaluating this MVP.
Synthetic regression-test fixtures are not a substitute for that catalog.

**Why:** The user requested real recipes from the web and proper database data
because they want to check whether their MVP is correct.

**How to apply:** Check the original recipe's quantities, timing and yield.
Keep a source link and preserve ranges or unspecified quantities rather than
inventing precise values. Distinguish source verification from kitchen testing.
