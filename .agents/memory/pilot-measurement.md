---
name: Pilot measurement hypothesis
description: Product hypothesis and the user-defined later-calendar-week conversion rule.
---

The primary Lean Startup hypothesis is: “Customers who use Tablewise to plan
dinners will find it valuable enough to return and plan another week.”

Return conversion means a completed plan in a later calendar week than that
browser's first completed plan. Opening the app or editing the same week's
plan is not a return conversion. This is a calendar-week planning proxy, not
necessarily an elapsed-week return visit.

**Why:** The user explicitly chose this hypothesis and conversion definition
for the minimal pilot, without accounts or unnecessary personal information.

**How to apply:** Interpret pilot reports using this definition; do not rename
page opens or same-week edits as retention, or claim synthetic test activity
validates customer demand. Any change to the conversion definition needs review.
